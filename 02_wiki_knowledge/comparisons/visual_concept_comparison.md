# 視覺與概念風格比較：賽博龐克極客 vs. 現代財閥名媛

> **摘要**：aespa 與 IVE 代表了第四代女團視覺美學的兩極端——aespa 聚焦於**數位未來主義、冷冽金屬質地與超現實機甲戰鬥裝**；IVE 則確立了**古典名媛奢華、精緻學院制服與純粹優雅的高定美學** `[SRC-03, SRC-04, SRC-05]`。

---

## 1. 核心視覺元素對照表

| 視覺維度 | aespa (SM Entertainment) | IVE (Starship Entertainment) |
| :--- | :--- | :--- |
| **視覺基調** | 賽博龐克 (Cyberpunk)、超現實科技感、Y2K 數位極客 `[SRC-03]` | 貴族名媛風 (Chaebol-Crush)、新古典主義、奢華法式清雅 `[SRC-04]` |
| **主導色系** | 極光色 (Aurora)、金屬銀、霓虹綠、深紫、暗黑幻彩 `[SRC-01, SRC-03]` | 皇家寶石藍 (Royal Blue)、象牙白、芭比粉、香檳金 `[SRC-02, SRC-04]` |
| **服裝材質** | 亮面乳膠皮革、反光金屬配件、戰術武裝帶、3D 打印裝飾 `[SRC-03]` | 絲絨、蕾絲、羊毛斜紋軟呢 (Tweed)、高訂真絲長裙 `[SRC-04]` |
| **道具與符號** | 虛擬化身 (æ)、戰鬥武器、數位傳送門、外星生命體 `[SRC-01, SRC-03]` | 鏡子 (象徵凝視自我)、皇冠、珍珠頸鍊、古典畫框、愛心符號 `[SRC-04]` |
| **成員視覺氛圍** | 精緻銳利的「AI/CG 般非人美感」 `[SRC-01, SRC-03]` | 自然生動的高挑名模骨相、貴氣大方的「天生名媛」感 `[SRC-02, SRC-04]` |

## 2. 空間與場景建構的差異
* **aespa：非實體與虛擬空間的穿梭**
  - 音樂錄影帶中充斥大量 CGI 渲染的數位異次元（如「FLAT」的懸浮方塊、「KWANGYA」的奇幻異界紫藤植物） `[SRC-03]`。
  - 成員往往置身於地下鐵列車突變、賽博摩天大樓頂端或崩裂的虛擬城市，展現抗爭與突圍的張力 `[SRC-03]`。
* **IVE：現實世界的高級生活場域投射**
  - 音樂錄影帶偏好使用古典宮殿、名媛豪宅挑高中庭、私人飛機機翼、無邊際水池與華麗宴會廳 `[SRC-04]`。
  - 場景不強調超自然破壞，而是營造「無憂無慮、自得其樂的奢華私領域」，讓凝視鏡頭的目光充滿自信從容 `[SRC-04]`。

---

## 3. 時尚影響力與品牌合作定位
* **aespa**：先後擔任 Givenchy 全球品牌大使、Chopard 蕭邦品牌大使，偏好具有前衛先鋒感、結構性強烈的高端時裝與實驗性街頭潮流品牌 `[SRC-05]`。
* **IVE**：成員分別深受頂級時裝品牌青睞（如張員瑛代言 Miu Miu、安兪真代言 Fendi 等），精準卡位青年名媛、精緻生活（Quiet Luxury / Balletcore）的潮流引領者 `[SRC-04, SRC-05]`。
